MD1T × XD10｜UI 功能定义介绍

FN 按键

  • 默认短按抬起翻到下一已开启展示页；仅短按可自定义，例如切换 Hz。
  • 长按满 2 秒固定进入 FN；松开不再触发短按。FN 内短按退出。
  • 仅 2.4G 可进入 FN；蓝牙、有线、配对中不可进入。FN 内鼠标只操作屏幕，不向电脑发送移动和点击。

FN 页面操作

  • 点击立即生效，退出保留，不需要确认或取消。
  • 调整箭头按住 2 秒后连续调整；松开、移出、换页或退出即停止。
  • 上下页按钮或 M4/M5 翻页；房子退出。连续 3 秒无操作自动退出，按住调整时不计作闲置。
  • 右键、滚轮不调参数；闪电图标只作性能标识。

通用规则

展示与侧键

  • 页序：时钟 → 鼠标 → 主机 → 相册 → 文字。驱动可关闭单页，至少保留 2 页。
  • 接收器侧键单击打开 TeevoLink；双击退出 FN、结束计时并翻页，不显示计时结果。单击和双击不能同时触发。
  • 记住上次页面和设置；重新供电不恢复上次运行中的计时。

同步与失败

  • 驱动、鼠标 DPI 键、FN 共用有效参数。外部改参立即同步，并停止当前连续调整。
  • 普通展示页显示改参提示 2 秒，可被翻页、FN 或计时打断；FN 和计时中不弹提示。
  • 修改失败保留原有效值，显示 UPDATE FAILED 2 秒。

文字与数据

  • 自定义文字支持静态与滚动显示，支持调整滚动速度、文字大小、文字颜色和背景颜色。静态模式超出可显示长度时提示缩短文字或切换滚动；滚动模式支持更长内容。字数上限及可调范围由芯谷确认。设备名称超长仍用省略号。
  • 主机动态数据每秒更新；连续 5 秒无有效数据显示 UNAVAILABLE，恢复后自动显示。设备名称变化时更新。
  • 时钟与电脑同步。Ping 显示指定目标的延迟，不代表游戏延迟。

交互反馈

  • 可用箭头白色，不可用箭头灰色，小框保留主题色；大框保留原灰色。ON/OFF 用选中状态区分。
  • 数值及普通枚举到边界停止；FPS 前后循环。光标、按下效果见“UI 设计 → 动效与光标”。

展示｜三款时钟

  • 显示时间、日期、星期、电量和连接状态；在 FN 第4页选择款式。

展示｜鼠标信息

  • 显示当前 DPI、回报率、LOD、Motion Sync、配置组、传感器 FPS。
  • X/Y 不同时分行显示；参数变化后同步显示最新值。

展示｜主机、相册与文字

  • 主机显示分辨率、刷新率、Ping、CPU、GPU、音频输出设备及键盘、鼠标信息。
  • 相册最多 4 张 PNG/GIF，GIF 最多 30 帧；单张展示或轮播，间隔 1～60 秒。
  • 驱动编辑自定义文字，并选择静态或滚动模式：静态居中显示；滚动模式下，无论长短均从右向左循环滚动。速度、字号、文字颜色和背景颜色可调。

FN 第1页｜DPI 与回报率

  • 修改当前 DPI 档数值；3950 步进 50，3955 步进 1。
  • X/Y 联动时同时修改；独立时点哪一行箭头就改哪一轴。关闭独立后，各档 Y 与 X 一致。
  • 鼠标 DPI 键切换 5 档：400 / 800 / 1600（默认）/ 3200 / 6400。
  • 回报率按当前固件支持档位切换；完整档表及默认值见待确认项。

FN 第2、3页｜鼠标设置

  • LOD：0.7 / 1 / 2 mm。Profile：1～4 组，只切换鼠标参数，不改变屏幕设置。
  • SENSOR FPS 是传感器帧率，默认 AUTO；点箭头循环切换 AUTO / 13000 / 20000。当前固件档位待芯谷核实，驱动不提供 FPS 选择。
  • Motion Sync：点击 ON / OFF，立即生效。

FN 第4页｜屏幕设置

  • 亮度 1～10 档，默认 10；只有驱动可关闭屏幕。
  • 相册固定4个档位，空档位也可选择；时钟选择 3 款之一；计时选择 4 个预设之一。
  • 修改计时预设只影响下一轮，不改变本轮计时。
  • V2 在时钟卡片内增加数字颜色选择，保留四块布局。

计时｜开始与运行

  • 计时器默认关闭。驱动开启，正计时/倒计时二选一，4 个预设，每档 1 秒～60 分钟。
  • 展示页 FN 短按开始；计时中短按停止。计时开启后，短按控制计时，优先于自定义 Hz 等功能。
  • 长按进入 FN，计时在后台继续；FN 内短按只退出 FN。退出时仍在计时则回到计时画面。

计时｜停止与到点

  • 手动停止显示停止时的已用时间或剩余时间；到点时强制退出 FN，并停止正在进行的调整。
  • 结果显示 5 秒，再回到计时开始前的展示页，不返回 FN；原页已关闭则到下一已开启页。
  • 结果期间短按按当前预设重新开始；长按进入 FN 并结束结果展示。
  • 显示优先级：固件升级 → 计时结果 → FN → 外部改参提示 → 低电提醒。

状态｜提示与异常

  • 外部改参：展示页提示 2 秒。失败：显示 UPDATE FAILED 并保留有效值。
  • 相册全空：显示 NO IMAGES；FN仍可选择1～4档，空档位旁显示无图片图标。部分为空：展示页显示当前档位及 NO IMAGE。
  • 数据缺失：对应项显示 UNAVAILABLE，恢复后自动显示。

V2｜低电与天气

  • 低电：20% 提示 3 秒，15% 再提示一次；FN 和计时结束后再提示，不打断操作。
  • 充电时不提示；同轮放电每个阈值只提示一次。充电恢复到 20% 以上后重新计次。
  • 天气显示城市、天气、温度；15 分钟刷新，30 分钟无更新显示 WEATHER UNAVAILABLE。
  • V2 功能：主题色、时钟/计时数字颜色、天气、低电提醒，开售后 30 天内 OTA。默认绿色主题、白色数字。三款时钟及正/倒计时均支持白、绿、蓝三色。只改变时间数字；日期、标题、进度条和图标保持原色。停止、到点结果沿用所选颜色。

交互｜光标、按钮与边界

  • FN 光标 26 × 32，热点 (2,2)：普通白色深色描边，悬停绿色描边，按下轻微缩小；展示页不显示光标。
  • 指向时按钮使用当前主题色的浅底，按下加深，松开约 120 毫秒恢复；绿色主题用浅绿底，蓝色主题用浅蓝底，只突出当前按钮。
  • 不可用按钮不高亮、不响应点击。切页直接切换；数字更新不闪烁、不改变布局。
  • 连续调整参考每 100 毫秒一步。低电提醒期间电量圈红色闪烁，每秒一次，共 3 秒。

固件升级｜鼠标

  • TeevoLink 发起鼠标升级，使用 2.4G 或有线连接；与接收器分开升级。
  • 显示真实进度。传输结束后显示等待设备，重新连接并确认升级成功后，再显示成功 3 秒。
  • 失败或连接中断显示失败，保留至驱动处理；从 TeevoLink 重试，屏幕不提供重试按钮。

固件升级｜接收器

  • 接收器通过 USB 单独升级，不依赖鼠标无线链路。
  • 进度、重连、成功和失败沿用鼠标升级的显示规则；不把传输完成直接当成升级成功。
  • 升级流程优先于计时和 FN：开始时退出 FN、结束本轮计时，不显示计时结果；升级后回原展示页，不恢复计时。
  • 开始升级前，驱动提示本轮计时将结束。升级中不响应 FN、翻页和设置操作；低电提醒延后。
  • 接收器升级/重启期间屏幕是否可用、进度及重连结果的上报方式由芯谷确认。屏幕不可用时，TeevoLink 继续提示，不承诺屏幕全程亮起。

光标｜设计原稿

  • cursor 文件夹内包含普通、指向、按下三态 SVG 与透明 PNG，均为 26 × 32；热点 (2,2)。
  • 仅 FN 显示；初始位置参考屏幕中心，移动至边缘仍保持完整可见。退出 FN 隐藏。
  • 不可用箭头和闪电图标不切换指向状态。上图下排为 3 倍放大对照，不是交付尺寸。

电量｜圆环与颜色

  • 圆环从顶部顺时针填充，长度对应剩余电量；百分比文字始终白色。
  • 50%～100%绿色 #78BE1F；21%～49%橙黄色 #F5B83D；0%～20%红色 #FF5252。圆内使用对应深色。
  • 平时不闪烁；20%和15%低电提醒仍各显示3秒，提醒期间红色环每秒闪一次。

电量｜低电与无数据

  • 0%显示空环和0%，不等于断连。只有有效数据才能显示百分比。
  • 电量缺失或失效显示灰环和“—”，不保留旧百分比。2.4G连接正常但电量缺失时，连接图标仍保持已连接。

状态｜充电与连接

  • 有效充电状态：百分比下显示闪电，圆环仍按电量和颜色规则变化；充电期间不弹低电提醒。
  • 收到充满状态：绿色100%并显示勾号；单独收到100%不能推断已充满。
  • 右侧只表示鼠标与接收器的2.4G连接：已连接为绿色无线图标；断开为灰色划线图标；配对中绿色外环每秒闪一次。
  • 断连保持原展示页，电量无有效来源时显示“—”；退出FN、结束本轮计时，不显示计时结果。重新连接不自动进入FN或重启计时。

状态｜插线与数据来源

  • 插线充电不等于切换有线。2.4G边充边用时，电量和充电状态由鼠标上报。
  • 拨钮中档插USB进入有线，鼠标直连电脑。接收器默认显示2.4G已断开、电量“—”。
  • 只有驱动明确同步有效电量与充电状态，接收器才显示对应信息；右侧仍表示2.4G断开。蓝牙不默认同步。
  • 待确认事项充电/充满状态上报、有线同步方式及数据失效时间。未确认的数据能力不作为已实现功能。

待确认事项

  • 接入：TeevoLink 地址、Ping 测试目标、主机及天气数据来源。
  • 素材：屏幕资源格式、中文字符范围及字库；具体实现和测试方案由芯谷确定；限制或差异请反馈确认。

相册空档位

相册固定4个档位。选到空档位时，编号旁显示灰色无图片图标；相册展示页显示当前档位暂无图片。自动轮播跳过空档位。

计时时长可按秒、分钟或小时输入，总时长范围1秒～60分钟。

自定义文字｜显示要求

  • 提供静态与滚动两种模式；速度、字号、文字颜色和背景颜色在驱动中设置，不增加 FN 页面。
  • 静态文字在当前字号下完整显示；超出长度时提示调整，不直接下发被截断的内容。
  • 滚动模式支持更长文字；内容连续可读，循环衔接自然。选择滚动时，短文字和长文字均从右向左循环滚动。
  • 字数上限、速度/字号范围和颜色支持由芯谷确认；DEMO中的数值仅为效果参考。
